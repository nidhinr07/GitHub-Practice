# Git & GitHub Commands

This repository contains a collection of important Git and GitHub commands that are commonly used in everyday development.

I created this as a simple reference for myself and for anyone who is learning Git and GitHub. Sometimes it is difficult to remember every command, especially when starting out. This cheat sheet can be useful to quickly check a command when you are confused or forget how something works.

The commands are kept simple with a one-line explanation so they are easy to understand and use.

## What You'll Find

- Basic Git commands
- Working with commits
- Staging and tracking files
- Working with branches
- Merging branches
- Working with GitHub repositories
- Push and pull commands
- Undoing changes
- Stashing changes
- Checking repository history

## Git Commands

Check the [Git Commands Cheat Sheet](git-commands.md) for the complete list of important commands.

## Purpose

The goal of this repository is to keep the most useful Git and GitHub commands in one place so that learners and beginners can quickly refer to them whenever they need help.

This is also part of my learning journey as I practice Git and GitHub while building projects.
