# 🚀 Git & GitHub Practice Sandbox

Welcome! This is a dedicated repository that I created to practice and learn **Git** and **GitHub**. 

## 🎯 Purpose
The main goal of this repository is to get hands-on experience with version control workflows without worrying about breaking real projects. 

## 🛠️ What I am practicing here:
* **Basics:** Initializing repositories, tracking changes, and staging files.
* **Commits:** Writing clean, meaningful commit messages.
* **Branching:** Creating, switching, and merging branches.
* **Remote Work:** Pushing local changes to GitHub and pulling updates down.
* **Collaboration:** Handling merge conflicts and creating Pull Requests.
